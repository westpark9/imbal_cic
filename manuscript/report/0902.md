# 0902 종합 — 진단 결과 정리 (중요도순)

기간 0831–0902. 용어 통일: **global** = frozen TabPFN + C0(1M 컨텍스트) / **시스템** = global +
개입층(scorer→expert→verifier) / **격차** = full XGB 0.7548 대비 macro-F1 / **대역** = 동일
설정 반복 시 변동폭. 평가는 전부 동일 4,023,114행. 상세 근거: 0831.md §0–§3.

## 1. 격차 분해 — "지고 있다"의 절반은 정보예산이었다

XGB를 global과 같은 조건으로 제한하며 재측정 (E-0.5, CPU):

| 학습 행 | macro | brute | ssh recall |
|---|---|---|---|
| XGB full 12.07M | 0.7548 | 0.9159 | 0.9995 |
| **XGB c0 1.00M** (global과 동일 행) | **0.7283** | **0.7246** | **0.0** |
| global (수리 전) | 0.6698 | 0.7246 | 0.0 |

- 격차 −0.055 = **정보예산 −0.0265 + 실질 −0.0305**.
- 같은 행이면 XGB의 brute도 **0.7246으로 우리와 동일** — brute 결손의 method 몫은 0.

## 2. 원인 A: 컨텍스트 구멍 → exp27로 수리 완료

pool 분할이 클래스내 시간순이라 C0에 **ssh·hulk·sql 0행**(hulk test 20,016행).
증거: random bank가 brute recall 0.9998로 그냥 고침 / SSH 50행 주입만으로 XGB-c0가
0.7283→0.7565 (50행에서 포화; hulk·sql은 주입해도 회복 안 됨 — SSH 특유).

**exp27(scenario 층화 분할) 결과**: global 0.6698 → **0.7277**(A100) / 0.7207±0.0006(로컬 ×3).
**brute 0.9159 = XGB와 동일**, dos 0.524→0.755+. **global ≈ xgb_c0 — 같은 정보예산이면
frozen TabPFN이 XGB와 동률**. 부작용: ddos 0.905→0.83~0.90(층화가 C0의 ddos 슬롯 잠식).

## 3. 재현성 — 옛 파이프라인은 판정 불가였고, 컨텍스트 수리가 절반을 고쳤다

동일 설정·seed 반복:

| 파이프라인 | global 대역 | 시스템 delta | K | harmful |
|---|---|---|---|---|
| 수리 전 (exp25 ×3) | 0.6663~0.6698 (**0.027** 포함 이전 run) | **+0.028 / −0.015 / +0.013 (부호 뒤집힘)** | 5↔6 | 4~1,132 |
| **수리 후 (exp29 ×3)** | 0.7201~0.7212 (**0.0011, 25배↓**) | 0 / +0.007 / +0.018 | 2↔5 | 0~214 |

- det-lite(bf16+결정성 커널) **실패** — bitwise 불일치, 1회는 게이트 셧다운.
- **fp32 A/B 판정 (0902 완료): TabPFN 층은 비트 단위 재현 성립** — gain_matrix_sha256 완전 일치
  (`e714009d…`, run 20260901_191613 vs 20260902_055231, 코드·args 동일·dense_eval만 차이),
  global macro 0.678456=0.678456, XGB full 0.754831=0.754831 (6자리). 그러나 **개입층 학습
  (scorer/verifier XGBoost)은 입력이 비트 동일한데도 산출물이 다름**: verifier 진단 e1
  false_accept 1,767 vs 56,358, τ_pre 0.90967 vs 0.93864, τ_post 1.0 vs 0.0 →
  **시스템 delta +0.0073 vs −0.0020, 부호 뒤집힘**. xgboost 3.2.0 자체는 동일 입력·스레드에서
  비트 결정적 + 1-ULP 섭동 흡수(로컬 검증) — 후보: 실행 간 스레드/OMP 환경 차 또는 개입층 특징
  (affinity/h_post)의 비트 차. 비용: 4090 불가(peak 24.36GB), A100 7.0h(dense 없이)~11.7h/run.
- 결론: **global의 잡음은 컨텍스트 구멍이 만든 것**(수리로 25배 축소). 남은 불안정은
  전부 **개입층**: K 선택 2↔5, **게이트 셧다운(τ_pre=∞, 보정 제약 불충족) 7회 중 4회**,
  delta 0~+0.018.

## 4. 원인 B·C: 개입층 — 문턱은 고쳤고, 예측 실패가 남았다

- 병목은 scorer가 아니라 **verifier**: τ_pre 전면 개방해도 채택 +1.7% / verifier↔실제 이득
  상관 ≤0.15, 출력 클래스-상수.
- 문턱 단위가 클래스 필터: ddos·benign은 오답 중 자격 0% (완벽한 expert로도 통과 불가).
- **exp26(단위 수정 G/w_bal)**: ddos 채택 **0→6,602** ✓, benign 289/204만 ✓, harmful 56 ✓,
  단 **inf 42행만** — verifier 예측 실패는 단위와 독립인 잔존 병목.

## 5. expert bank 가치 — 기각

- **Gate 1 (등메모리, exp28)**: residual 0.8300 < random 0.8453 < **proximity 0.8857**.
  residual mining이 무작위 선택에 짐.
- diversity selector는 expert 5개 중 4개에서 비활성(regime ≤ 블록 예산).
- **K=1 (exp29 기반)**: delta +0.0018(대역 안), **oracle 0.8837 ≥ K=5 oracle 0.84** —
  K 다중화 근거 없음.
- λ 스윕(0.1/1.0/21.145): **3회 전부 게이트 셧다운으로 판독 불가** — wasted-call 축은
  λ로 못 고침, 보정 제약의 실현 가능성 문제.

## 6. 현재 위치와 남은 격차

| | macro | vs XGB |
|---|---|---|
| XGB full | 0.7548 | — |
| **시스템 최고 (exp29 r3)** | **0.7395** | −0.015 |
| global (수리 후, ×3 중앙) | 0.7207 | −0.034 |
| dense oracle (exp29) | 0.81~0.88 | +0.06~+0.13 |

남은 격차의 구성: **ddos**(0.83~0.90 vs 0.992 — 층화 부작용 + 개입은 exp26으로 열림)와
**infiltration**(0.39 vs 0.43 — verifier 예측 실패; oracle 0.97로 회수분 존재). 나머지
클래스는 동률 또는 우위.

## 7. 서사 (데이터가 가리키는 결론)

1. **"컨텍스트 구성이 아키텍처보다 중요하다"** — 층화 C0만으로 global이 matched-budget
   XGB와 동률, 재현성 25배 개선. (문헌 동조: Data Presentation Over Architecture, 2026 —
   docs/tabpfn_imbalance_papers.xlsx #4)
2. **residual expert bank 우위 주장은 폐기** — Gate 1 기각, K=1 동등, selector 비활성.
3. 개입층의 남은 가치는 **"드물고 정확한 조건부 개입"**(ddos +0.015, dos 회복)이나
   **안정화가 선행 조건**(셧다운 4/7, delta 대역 0.018).
4. IID 승부의 잔여 목표는 ddos·inf 두 클래스, 합계 ~+0.02 여지 → 0.755±는 산술적으로 사정권.
