**원노브 = 선언된 패키지 5부** (guide가 Phase 1로 묶은 단위; CLAUDE.md "두 knob이
필요하면 로그에 명시" 조항에 따라 패키지로 선언):

1. **residual clip** (guide §8): `r̄=min(r, quantile(r, --residual-clip-q=0.995))` —
   클러스터링·선택 가중치와 signature의 severity 블록에만 적용. Δ(advantage)
   타깃은 비클립 유지(verifier층은 이번 knob 밖).
2. **full residual signature** (guide §9): `e=[std(z) | α_p·std(p0) |
   α_e·std(onehot(y)−p0) | α_r·std(log1p(r̄))]`, 블록별 개별 표준화 후
   α/√dim 스케일(α=1이면 블록 기여 균등). 표준화 통계는 D_mine에서 fit.
3. **r̄-가중 k-means를 e-공간에서** (기존: z만, 비클립 r).
4. **hard regime assignment** (guide §11.2 = 0825 §6 후보 c-1): S_k는
   R_k={argmin d=k}에서만 — 클론을 구성적으로 차단(블록 간 Jaccard=0 보장).
5. **regime 내 diversity-aware 선택** (guide §11.2 weighted k-center 근사):
   r̄-가중 MiniBatchKMeans(`--diversity-subclusters=2048`) cell이 coverage 정의,
   예산은 r̄-질량 비례 largest-remainder(비어있지 않은 cell ≥1, 크기 상한),
   cell 내 top-r̄. TopB·`--tau-c` 완전 제거.

+ guide §11 필수 다양성 진단 상시 기록: 2b 블록 Jaccard · 3c expert 예측
일치도 · 3d gain 상관 · 3e positive-gain coverage (+ quality에
block_jaccard_max/gain_corr_max).

## §4. EXP23 사전 등록 — guide 정합화 패키지 (전체 md 재감사 → 미반영 시스템 요소 일괄 구현) (결과 전 고정)

사용자 지시: "§18 같은 미반영 사항을 전체 md에서 감사해 exp23으로." 스크립트:

보유로 무수정). **선언된 다중-knob 패키지** — 각 층은 grid/flag로 분해 가능:

- **P0 §5 6-way split**: train→D_global/D_expert/D_route(50/25/25, exp22c
  연속성) + **미사용이던 val**을 클래스별 시간순 40/60으로 D_tune/D_cal
  (pre-test 비율 ~37/19/19/10/15 ≈ guide 40/20/15/10/15; 시간순
  train<val(tune<cal)<test 전 구간 보존). test=development holdout 명명.
  0c manifest(행수·시간범위), §18 개명 D_mine→D_expert(코드·CLI).
- **P0+ §5 중복 집행**: β/T·K·pruning은 C0/anchor/D_expert와 content-중복인
  tune 행 제외, 보정/threshold는 D_route와 중복인 cal 행 제외(마스크 수
  로그·클래스 공동화 시 fallback 기록). pairwise dup-hash 행렬 0d.
  source_file/session 부재는 데이터 한계로 기록.
- **P2 §7 prior correction**: 컨텍스트별 π̂(α=1 평활), π_ref=D_global 분포,
  z̃=log p+β(log π_ref−log π̂), softmax(z̃/T); (β,T)는 D_tune 균형 NLL grid
  {0,.5,1}×{.8,1,1.25} (β=0 행이 필수 ablation, 1c). global·expert 전체 적용.
- **P2 §10 K 선택**: `--k-candidates 2,4,8` bank별 tune oracle macro로 선택
  (2d) — K=4 휴리스틱 제거.
- **P2 §12 pruning**: tune positive-gain coverage<0.005 또는 marginal oracle
  macro≤0.001인 expert 제거(2e), 최소 1개 보존, 제거분 캐시 즉시 해제.
- **P3 §15 shared utility scorer**: (query,expert) pair 회귀, h_pre에

**은행 정체 (7a 복원) — 가설의 성공 부분**: anchor 균형성을 제거하자
marginal이 재분화되어 **처음으로 원하던 순수 전문가들이 greedy를 통과** —
nat200: inf-순수 15.6k + web-순수 135 + mega · nat2000: **dos-순수 +

inf-혼합 + dos-혼합 + mega (web-편향 anchor가 전 expert 오염).

**그러나 회수층이 무너짐 — 가설의 실패 부분**: natural-anchor expert는
비전문 클래스 posterior가 자연비율에 눌려, balanced-loss 기반
scorer/verifier가 ① 이득 추정을 못 하고(recall 0.05~0.09), ② 유해
override를 통과시킴(nat200 harmful 772 전부 benign·inf 붕괴; nat2000
web 붕괴). inv200은 web-과대 posterior로 benign FPR 6×.

**중대 부수 발견**: nat200에서 random bank 0.8229 ≈ residual oracle
0.8323 — **균형 anchor가 없으면 residual 구성의 대조군 우위도 거의
소멸**. 즉 지금까지의 "residual 신호"(Gate-1)의 상당분은 [균형 anchor ×
블록]의 결합 효과였음. anchor는 단순 균열이 아니라 **회수층의 안전판이자
oracle 우위의 공동 원천**인 양면 부품.

생존), ② min-support pruning(9행 regime 방지), ③ recall 0.05~0.16
