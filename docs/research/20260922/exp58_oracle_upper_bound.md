# EXP58: 고정 bank의 Accuracy·Macro-F1 상한

기존 다섯 조건을 보존하고 6번에 정답 참조 bank selector를 추가했다. 선택 가능한 답은 같은 행에서 고정 global·expert가 실제로 출력한 클래스뿐이다. 정답이 후보 안에 있으면 그 답을 사용하고, 모든 후보가 틀린 행도 반드시 후보 중 하나를 출력한다. Test 정답을 사용하는 달성 불가능한 참조이므로 expert 생성 품질의 근거나 실제 일반화 성능으로 해석하지 않는다.

| 데이터 | 현재 S+V Macro-F1 | 전체 bank Macro-F1 상한 | 전체 bank Accuracy 상한 | 현재 호출 위치를 고정한 Macro-F1 상한 |
|---|---:|---:|---:|---:|
| CIC2018 | 0.810653 | 0.991366 | 0.999503 | 0.810653 |
| ToN | 0.755490 | 0.786694 | 0.920577 | 0.757126 |

전체 bank 상한은 호출 위치·scorer·verifier를 이상적으로 선택하고 비용과 운영 FPR 제약을 적용하지 않은 상한이다. 호출 위치 고정 상한은 실제 호출하지 않은 행에서 global만 허용하고, 호출한 행에서 global과 모든 expert를 허용한다. 같은 제약 안에서 선택기만 바꿀 때의 상한이며, 전체 모델 구조의 상한과 구분한다.

현재 bank는 CIC K=8/C=7, ToN K=7/C=10인 기존 EXP47·48이다. 따라서 CIC 결과는 새 K<C 설계를 만족하는 bank의 결과가 아니다. K=4 재학습은 EXP57로 별도 실행 중이다. 두 데이터 모두 기존 모순 제거 개발 holdout을 사용한다.

## 기존 global fallback과의 차이

정답 후보가 있는 모든 행을 맞히면 Accuracy는 상한에 도달한다. 하지만 모두 틀린 행에서 global을 유지하는 규칙은 Macro-F1을 최대화하지 않을 수 있다. 그 행의 오탐을 어느 클래스에 배정하는지가 Macro-F1을 바꾸기 때문이다. 기존 global fallback 방식의 Macro-F1은 CIC 0.962640, ToN 0.784667이며, 이번 계산은 남은 오답의 선택도 최적화했다.

## Macro-F1 최적화

맞힐 수 있는 행은 모두 맞히는 것이 각 클래스 F1에 불리하지 않으므로, 최적점에서는 TP·FN이 고정된다. 남은 행은 후보 클래스 집합별로 묶고 FP 목적지 선택만 최적화한다. 목적함수는 `mean(2 TP_c / (support_c + TP_c + FP_c))`로 FP에 대한 분리 가능한 볼록 함수다.

최적점에서 어떤 후보 집합의 오답 목적지를 더 큰 편미분을 가진 클래스로 옮길 수 있다면 볼록 함수의 기울기 부등식에 따라 목적함수가 증가하므로 최적점에 모순된다. 양의 TP를 가진 클래스 사이의 편미분 동률도 엄격 볼록성 때문에 유리한 이동을 만들며, TP=0인 클래스끼리의 동률은 목적함수를 바꾸지 않는다. 따라서 어떤 최적해는 클래스의 단일 우선순위에 따라 각 후보 집합의 첫 클래스를 고르는 형태로 표현된다.

클래스 부분집합 DP로 모든 우선순위를 `O(C 2^C)`에 비교했다. 이는 임의 탐색의 최고값이 아니라 이 고정 bank와 행별 자유 선택이라는 정의 안에서의 정확한 최댓값이다. 작은 문제 120개에서 가능한 모든 행별 선택을 열거한 결과와 일치함을 테스트했고, 출력한 oracle 예측 배열의 F1이 DP 값과 일치함을 검증했다. 클래스별 독립 F1 상한은 동시에 달성되지 않을 수 있으므로 별도 열로 구분했다.
