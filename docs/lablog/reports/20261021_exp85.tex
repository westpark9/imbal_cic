\subsection{목적과 실행 상태}
모델의 효과와 사례 구성의 효과를 분리하기 위해 EXP84에서 PFN이 사용한 각 단계의 버퍼를 XGB 학습에 그대로 제공한다. 연구 버전은 v7이며 현재 상태는 완료, 새 실행 108/\allowbreak{}108조건이다. 전체 예측 검증을 마친 seed는 [43, 44, 45]이며 기록 시각은 2026-10-21 14:38:55 KST다. 사용자는 2026-10-21에 XGB 버퍼 대조군 추가와 슬라이드 개편을 요청했다.

기존 EXP84의 seed 43·44·45는 완료되었으며 PFN 예측과 누적 XGB 결과를 재사용한다. 무작위 정책도 단계별 실제 행 ID가 저장되어 있어 PFN 재실행이 필요 없다. XGB 버퍼 조건의 학습·예측·시간은 새로 측정하며, 기존 PFN과는 실행 세션이 다르다는 점을 비용 해석에 포함한다.

\subsection{설정과 단계별 재학습 이유}
신규 공격당 5·10·20·30·50·100개, CIC2018과 ToN-IoT, seed 43·44·45를 유지한다. 초기 사례는 정상 750개와 초기 공격 두 클래스 각각 125개다. CIC은 초기 Benign/\allowbreak{}Brute force/\allowbreak{}DoS 이후 DDoS, Web attacks, Infiltration, Bot을 도입한다. ToN은 초기 Benign/\allowbreak{}Scanning/\allowbreak{}DoS 이후 Injection/\allowbreak{}DDoS, Password, XSS, Ransomware/\allowbreak{}Backdoor, MitM을 도입한다.

고정 버퍼는 1,000개이며 공급된 신규 사례를 모두 편입하고 같은 수의 기존 사례를 삭제한다. FIFO·무작위·유사도는 EXP84의 동일 규칙이며 기존 클래스별 최소 1개를 보존한다. 이번 추가 정책은 무작위, FIFO, 유사도이다. 삭제를 실제로 다시 계산하면서 시간을 측정하고, 각 단계에서 PFN의 저장된 행 ID·순서와 완전히 일치하는지 검사한다.

최종 품질만 필요하다면 마지막 버퍼로 XGB를 한 번 학습해도 된다. 이번 비교는 후속 갱신 시간 합계와 기존 클래스 유지도 평가하므로 모든 단계에서 XGB를 새로 재학습한다. 각 단계에서는 고정 패널만 예측하고 전체 test는 마지막 모델에서만 예측한다. XGB는 300 trees, depth 8, learning rate 0.05, CUDA histogram, threads 8이며 PFN은 IDS 가중치 fine-tuning 없는 기존 v3 결과다.

\subsection{평가와 비용 범위}
최종 전체 test는 CIC 3,042,473개와 ToN 2,271,723개이며 seed 43의 같은 query 순서와 batch 8,192개를 유지한다. 신규 공격군 평균은 마지막 전체 test 혼동행렬에서 CIC 4개·ToN 7개 신규 공격의 F1을 같은 비중으로 평균한다. 기존 성능 유지는 클래스당 최대 2,000개 고정 패널에서 초기 세 클래스의 최종−초기 Macro-F1으로 측정한다. 패널과 전체 test는 서로 다른 평가 모집단이며 패널의 미래 클래스 특징은 오프라인 진단에만 사용한다.

주 비용은 2단계 이후 선택/\allowbreak{}삭제·모델 구성·fit/\allowbreak{}cache 시간의 합계다. 초기 준비, 모든 추론, 체크포인트 저장, 검증은 제외하여 기존 PFN과 기준을 맞춘다. 추론 시간은 별도 수치로 보존하며 갱신 시간의 우위를 전체 운영 비용 우위로 해석하지 않는다. 정확히 같은 행을 사용하지만 모델 학습 방법과 사전학습 여부는 각 방법의 특성으로 유지한다.

평균과 표본 표준편차(ddof=\allowbreak{}1)는 조건별 seed에서 계산한다. XGB 대비 PFN 차이는 같은 seed·같은 정책·같은 행의 결과끼리 뺀 뒤 집계한다. 부분 완료 시 전체 검증을 마친 동일 seed 집합만 양쪽 곡선에 사용한다. 세 seed는 고정 train/\allowbreak{}test 분할에서의 반복이며 표준편차는 신뢰구간이나 동등성 검정이 아니다.

\subsection{해석과 후속 판단}
전체 48개 데이터셋·라벨 수·정책 조합 중 PFN의 전체 F1 평균이 더 높은 조건은 44개, 신규 공격군 F1 평균이 더 높은 조건은 40개다. 이는 동일 사례를 사용한 세 seed 평균의 방향을 센 기술 통계이며 유의성 검정이나 새로운 분할에서의 승률이 아니다. 따라서 PFN의 차이를 버퍼 구성만의 이점으로 설명할 수 없지만 모든 조건의 우위도 주장하지 않는다.

n=\allowbreak{}100 ToN에서 FIFO의 전체 F1은 PFN 70.10\%, XGB 61.64\%다. 각 모델의 누적 조건과 비교하면 PFN은 +\allowbreak{}2.02 pp, XGB는 -5.49 pp 변했다. 같은 삭제가 두 모델에 같은 효과를 주지 않으므로 모델과 사례 구성의 상호작용을 분석해야 한다. 이 조건의 전체 점수 향상만으로 초기 클래스 유지나 모든 신규 공격 개선을 대신 입증할 수는 없다.

예외도 남는다. n=\allowbreak{}100 ToN의 누적 신규 공격군 F1은 XGB 66.89\%, PFN 65.64\%이며, 유사도 버퍼의 전체 F1도 XGB 60.35\%, PFN 58.66\%다. 전체 평균, 신규 공격군, 기존 클래스 유지 및 희소 클래스 결과를 분리하여 정책 선택의 근거로 사용한다.

후속 갱신 시간의 평균은 48개 조합 모두 PFN이 낮았고, 동일 정책 XGB와의 차이는 0.50\textasciitilde{}4.23초였다. PFN이 다른 실행 세션에서 측정되었으므로 세션 간 변동의 영향을 배제한 정밀 벤치마크로 해석하지 않는다. 버퍼 1,000개 및 작은 누적 사례 범위에서 가중치 학습을 생략하는 갱신 경로를 지지하는 관찰로 한정한다.

ToN Ransomware의 누적 F1은 XGB 17.11\%, PFN 6.19\%이고, 무작위 버퍼에서는 각각 5.86\%, 4.94\%다. PFN 무작위의 평균 재현율 96.66\%와 정밀도 2.55\%는 탐지 누락보다 오탐을 우선 분리해 분석할 근거다. 삭제 없는 누적에서도 약점이 남으므로 버퍼 크기만 늘리면 해결된다고 단정하지 않는다. 다음 개선안은 오탐 출처와 보유 클래스 비율의 관계를 점검하고, 학습용 검증 집합에서의 확률 보정과 가중치 적응을 별도로 평가하는 것이다. 보정·적응의 효과는 이번 실험에서 검증하지 않았다.

같은 버퍼에서 XGB와 PFN이 모두 개선된다면 데이터 구성 효과를 먼저 검토한다. PFN이 비슷한 품질로 더 빠른 갱신을 보이면 가중치 재학습 생략의 적용상 이점으로 해석할 수 있다. XGB가 같은 버퍼에서 더 좋은 품질과 충분히 낮은 비용을 보이면 해당 조건의 PFN 채택 근거를 재검토한다. 낮은 희소 클래스 F1은 클래스별 정밀도·재현율·오탐을 분석하여 개선 방향을 정하며 전체 평균만으로 가리지 않는다.

버퍼 정책은 클래스별 보유 비율도 바꾼다. FIFO는 확보 순서에 따른 삭제이며 실제 트래픽 노후화 판정이 아니다. 새 클래스만 들어오는 현재 시나리오에서 정상·기존 공격을 추가 공급하지 않으므로 실제 운영 분포 변화와 동일하다고 주장하지 않는다. 원본 행 ID는 train/\allowbreak{}test에서 다르지만 같은 특징 벡터는 남을 수 있으며 기존 중복 특징 제외 진단을 유지한다.
