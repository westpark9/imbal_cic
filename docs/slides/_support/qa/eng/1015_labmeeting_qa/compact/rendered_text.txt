TabPFN · Pretrained prediction rules for tabular data (v3: arXiv, 2026)


Pretraining          Pretrained on over 8 trillion tokens of synthetic tables
                     Learns prediction rules by predicting hidden targets


In-context           Predicts a new flow using labeled examples as context
learning             Model weights remain fixed during inference

Fine-tuning          Splits initial IDS data into context and query examples
                     Backpropagates query loss to adapt the model weights


  Update: fixed pretrained weights → retain old classes and add new examples
  Hypothesis: comparable detection quality with fewer labels and lower update cost

v3 architecture

                  ① Encode inputs · Cell embedding
                  Converts values such as packet length into vectors
                  Also indicates which entries are missing

                  ② Summarize columns · Feature embedding
                  Summarizes each feature across multiple flows
                  Uses the benign and attack labels in the context

                  ③ Combine features · Feature aggregation
                  Combines each flow’s features into one representation
                  Uses it to compare relationships between flows


                                                                          3
v3 architecture


                  ④ Consult examples · In-context learning
                  A new flow queries the labeled context examples
                  Attention identifies relevant examples for prediction



                  ⑤ Predict probabilities · Many-class decoder
                  Assigns greater weight to labels of relevant examples
                  Combines them into benign and attack probabilities

                  Keep context examples of existing classes
                  to continue predicting those classes
