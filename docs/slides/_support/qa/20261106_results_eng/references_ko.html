11/06 From CSV to PCAP
CSV inputs showed clear limits, so features are now built directly from raw packets
Prior experiments
CICFlowMeter CSV vectors XGB · TabPFN SOTA · proposed models Evaluation scenarios attempted
Problems found
Weak classification Same features, different labels Some attacks score high even in few-shot, leaving little to gain
This report
PCAP instead of CSV Features from netFound, a transformer encoder for network data
Question Do packet-based features fix these problems?
Build features from PCAP with the netFound encoder and test whether the problems improve
