소수 신규 공격 사례에 대응하는 IDS
침입 탐지 시스템(IDS) · 통신 기록의 특징으로 정상·공격 유형 분류
처음 확보한 라벨에 없는 공격의 등장 고정된 분류 점수만으로 파악하기 어려운 신규 사례 반영 능력
운영 시작
정상 + 공격 A·B 일부 유형의 라벨만 확보
추가 조사 이후
새 공격 C의 라벨 소량 확보 기존 탐지기에 반영할 필요
갱신 후 확인
C 탐지 품질과 갱신 비용 기존 정상·A·B 구분 유지
XGBoost
새 사례를 포함한 누적 라벨 데이터로 모델 재학습
TabPFN
사전학습 모델에 기존·신규 사례를 context로 제공
이번 평가 범위 · 새 공격의 라벨 확보 이후 적응
비교 질문 · 소수 신규 사례에서 얻는 탐지 품질과 갱신 비용

TabPFN · 사전학습 가중치와 입력 사례의 역할
합성 표 과제로 예측 규칙 사전학습 · TabPFN-3, arXiv 2026
사전학습된 것은 사례에서 예측하는 방법 현재 IDS의 정상·공격 클래스에 해당하는 사례는 추론 시 입력
Context
기존·신규 특징 + 라벨
Query
분류할 기록 · 정답 미입력
TabPFN
사전학습 가중치 고정
클래스별 확률
정상 · 공격 A · 공격 C …
In-context learning
context와 query의 관계를 이용한 예측 · 가중치 갱신 없음
Fine-tuning
IDS 사례를 context/query로 나누고 query 정답 손실을 역전파 별도의 가중치 추가 학습 · 이번 비교에서는 미수행
가중치를 고정해도 필요한 context · 현재 분류 문제를 알려 주는 라벨 사례

v3 구조 · 통신 기록의 표현
1 입력값 표현 · Cell embedding
패킷 길이 등 각 값을 벡터로 변환 결측 여부도 함께 입력
2 열 정보 요약 · Feature embedding
여러 기록에서 각 특징의 분포 파악 context 라벨을 함께 참조
3 행 정보 통합 · Feature aggregation
한 기록의 특징들을 하나의 표현으로 통합 사례 간 관계 비교에 사용할 행 표현 생성
02 3
v3 구조 · 사례 참조와 갱신 비용
4 사례 참조 · In-context learning
query와 context 사례의 관계 계산 attention으로 참고할 사례의 비중 결정
5 확률 출력 · Many-class decoder
context 라벨을 가중합해 확률 계산 정상·기존 공격·신규 공격의 사례 모두 필요
가중치 학습 없이도 발생하는 갱신 비용
context 전처리 · 표현 계산 · 캐시 준비 XGB 재학습보다 저렴한지는 실측으로 비교
가중치 추가 학습의 부재와 낮은 갱신 비용을 구별한 비교
