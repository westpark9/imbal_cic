별도의 context 실험 결과 본문 장은 삭제하고 상세 expert·K별 결과는 부록에 보존했다. SOTA는 현재 고정 holdout에서의 성능을 보여주는 역할이며, 신규 공격 갱신 효용을 입증한 결과로 해석하지 않는다. 제안 모델은 기존 anchor+residual, K=4, S/V 포함 EXP63 결과를 사용한다. EXP70은 Global 갱신 방식의 비교이므로 완료되어도 제안 모델 완전판 결과를 대신하지 않는다. 진행 중 실험은 설계와 상태만 표시하고 미완료 성적을 만들지 않는다.
