TabPFN · 표 데이터 예측 규칙을 사전학습한 모델 (v3: arXiv, 2026)


사전학습           합성 표 데이터의 8 조 개 이상 토큰으로 학습
               일부 행의 정답을 맞히며 표 데이터의 예측 규칙 습득


In-context     라벨된 사례 (context) 를 참고해 새 flow(query) 의 라벨 예측
learning       추론 중 모델 가중치는 그대로 유지

Fine-tuning    초기 IDS 를 context 와 query 로 나눠 query 의 정답 예측
               예측 오류를 역전파해 모델 가중치를 IDS 에 맞게 조정


 갱신 : 사전학습 가중치 유지 → 기존 클래스 사례 보존 + 신규 사례 누적
 기대 : 반복 재학습과 비슷한 탐지 품질을 더 적은 데이터 · 갱신 비용으로 달성

v3 구조

        ① 입력 변환 · Cell embedding
        패킷 길이 · 지속시간 등의 값을 숫자 벡터로 변환
        값이 비어 있는 위치도 함께 표시

        ② 특징별 분포 파악 · Feature embedding
        여러 flow 를 살펴 각 특징의 값 분포를 요약
        Context 의 정상 · 공격 라벨도 함께 반영

        ③ Flow 별 정보 통합 · Feature aggregation
        한 flow 의 여러 특징을 하나의 표현으로 통합
        이 표현을 이용해 flow 사이의 관계 비교


                                               3
v3 구조


        ④ 사례 참조 · In-context learning
        새 flow(query) 가 라벨된 기존 사례 (context) 를 참조
        어떤 사례가 예측에 도움이 되는지 attention 으로 계산



        ⑤ 확률 출력 · Many-class decoder
        관련성이 큰 사례의 라벨에 더 큰 가중치 부여
        참고한 라벨을 모아 정상 · 공격별 확률 계산

        기존 클래스도 분류하려면
        해당 라벨의 context 유지 필요
