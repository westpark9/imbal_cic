TabPFN 도입 이후 연구 기록

2026-08-18 – 2026-09-08 기준 · frozen TabPFN 위에서 컨텍스트 구성과 조건부 개입으로 XGBoost를 넘는 것을 목표로 한 세 주간의 기록.

TabPFN-v2 메모리 조사에서 시작해, TAILGUARD(에너지 게이트 + family expert)를 접고 제안 모델(Ours) — frozen TabPFN 위에서 글로벌 모델의 실패로부터 expert context를 자동 발견·조건부 호출 — 로 전환했다. 8월 내내 XGBoost(0.7548)를 넘지 못했지만, 9월 초 병목을 분할 방법과 채택 단위로 정확히 특정한 뒤, 컨텍스트 구성 + config 앙상블만으로 9월 4일 7개 seed 전부가 XGBoost를 넘었다 — 개입층 없이.

핵심 발견 (최신순)

  1. (09-08) 외부 PFN-scaling SOTA는 같은 정보 예산에서 ours를 넘지 못한다. 같은 100k C0를 풀로 주어도 BoostPFN(부스팅 가중치가 학습 불가능한 inf 행에 붕괴, 후반 γ≈0)과 LoCalPFN(국소 검색이 라벨 충돌 지역에서 head 상실, 미세조정은 inf를 판다)은 −0.022–−0.050; DistPFN은 C0가 꼬리를 과대표집한 컨텍스트라 보정이 꼬리를 깎아 중립(−0.0008). 릴리스 코드의 DistPFN-T 분기는 실행 불가라 제외.

  2. (09-04) config 앙상블이 진짜 "복권"을 없앤다. 같은 C0 표본이라도 TabPFN의 단일 config(random_state)에 따라 macro-F1이 0.675↔0.750을 오갔다 — n_estimators=4로 바꾸자 100k 균등 7 seed가 0.758–0.769로 수렴, 7/7 XGB 상회·붕괴 0/7. 안전 변수는 비율이 아니라 C0의 benign 절대 행 수(≤190k에서 12/13 무사).

  3. (09-02) 격차의 절반은 정보예산, 나머지는 두 클래스. XGBoost와 같은 1M행만 주면 global 0.7207≈XGB-c0 0.7283. 남은 격차는 ddos·infiltration에 집중 — expert bank 가설은 등메모리 무작위 선택보다 낫지 않아 기각, 서사는 "residual expert bank"에서 "컨텍스트 구성 + 드물고 정확한 조건부 개입"으로 이동.

  4. anchor의 양면성. 공유 균형 anchor(2k/class)는 leave-one-out marginal을 눌러 pruning을 붕괴시키지만(exp23), 제거하면 expert의 비전문 posterior가 무너져 회수층 전체가 실패(exp23c/d).

  5. pruning 측정은 regime-조건부여야 함. expert의 marginal을 자기 regime 행에서 재면 anchor 기여가 상쇄되어 전문가가 생존(exp24a).

  6. scorer는 절대-이득 회귀가 아니라 부호 문제. sign 분류로 recall 0.09→0.26 (exp24b) — 9/2 진단에서 이 자리를 ΔNLL 단위로 다시 교체.

  7. temporal drift의 명명된 증거. hard-brute regime = ssh_bruteforce(2/14 18:01 개시). frozen global은 test의 SSH 37,696행을 전량 오답 — C0 구성 캠페인에서 이 벡터(port-21)가 macro를 ±0.13 흔드는 것으로 재확인됨.

  8. prior shift는 차별화 축이 아니다. XGB posterior가 재가중을 견딜 만큼 날카롭고 TabPFN posterior는 sharpness 부족.

다음 단계

  2. 다른 3개 데이터셋(bot_iot, ton_iot, unsw_nb15)으로 구성 규칙 이식 — cic2018에서 찾은 "100k + benign 0.75 + 공격 균등 + config 앙상블 4"가 일반화되는지.
  3. 개입층을 global + 균형 컨텍스트 1개 + 무학습 트리거(p_benign<θ) + D_cal 클래스 조건부 채택표로 교체 — scorer/verifier(XGB 34-d, route 창 학습)는 test에만 나타나는 실패를 배울 수 없음이 r3에서 확인됨.
