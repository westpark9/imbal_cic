RACE-PFN — Residual Advantage-Guided Context Experts

frozen Tabular Foundation Model Fθ 위에서, global이 실패하는 residual regime을 실패 서명으로 자동 발견해 서로소 context expert로 만들고, shared utility scorer가 순이득을 예상할 때만 top-1 expert를 호출하며, 보정된 하한 Glower>τpost일 때만 교체하는 전체 구조 (exp23 · guide 정합).

1 · expert들은 "비슷"하지 않았다. 사후 복원(7a: mining_dump의 K=8 배정 × 라벨)으로 확인 — 8개 regime은 brute 순수·inf 순수·web 순수·dos 순수·혼합 2종·mega·경계로 명확히 상이했고, 블록 행도 전혀 안 겹친다(2b Jaccard 0). Phase-1 컨텍스트 구성은 제 역할을 했다.
2 · 그런데도 서로 대체 가능했던 이유 = 공유 anchor. 모든 expert 컨텍스트는 anchor(클래스당 2,000행, 계 12,761) ∪ 전문 블록이다. tune oracle 관점에서 brute 행 하나는 brute-전문 e2가 아니어도 어느 expert든 자기 anchor의 brute 2,000행 덕에 자연비율 global보다 잘 맞힌다 — 그래서 e2를 빼도 잃는 것이 없고(marginal 0.0003), 실패 질량이 최대(0.336)인 brute 전문가가 잘려나간다. coverage 0.31–0.75는 블록이 아니라 anchor가 만든 공통 일반의 능력의 흔적이며, exp22부터 추적해 온 "positive-advantage ~90%" 균열과 같은 뿌리다. 결정적 산수 — 유일 생존자 e1을 빼도 나머지 7명이 tune oracle 0.9496을 유지한다(0.9728−0.0232): 골키퍼 여덟을 한 명씩 빼보며 "골대는 지켜지니 불필요"라 결론 내리고 일곱을 벤치로 보낸 구조다.
3 · e1(dos)만 살아남은 이유. dos는 anchor 2,000행으로는 부족하고 21k 전문 블록이 있어야만 풀리는 유일한 클래스다(global dos .488 — 시리즈 최난). 증거: e1 단독 oracle이 dos에서 .9949인 반면 brute에서는 .8041에 그친다 — anchor 일반의 효과의 상한. brute 전문가가 살아 있었다면 ~.92 수준(random bank의 brute .9159가 그 대용 증거).
4 · 잘린 전문가 = XGB에 지는 클래스, 1:1 대응. e2(brute) 제거 → brute .7246 vs XGB .9159, e3(inf) 제거 → inf .4203 vs .4291, e8(web 140행, 평균 잔차 2,354) 제거 → web 미회수. 이것이 "global은 이기고 XGB엔 지는" 현재 위치의 직접 원인이다.
→ 처방(다음 원노브): ⓑ greedy backward pruning — 하나 뺄 때마다 marginal 재계산; e2·e3·e8은 "마지막 남은 전문가"가 되는 시점에 marginal이 커져 생존한다(1순위). ⓐ anchor 구조 — 전원 공유 준-균형 anchor가 marginal을 눌러버리는 근본 원인(§7 prior·§12·§15 균열의 공통 뿌리). 이 둘을 잡기 전에는 라우팅 지표(⑤)의 회수율 개선을 논할 수 없다.

1 · 두 knob은 설계대로 작동했다. regime-조건부 측정은 anchor를 유지한 채 marginal을 1.0~10.2로 분리해 exp23b의 "쌍둥이 동시 붕괴"를 해결했고(24a 2e), sign-scorer는 제안 recall을 0.086→0.18~0.26으로 3배 열면서 τ를 확률 단위로 안정화했다. ablation 귀속: 24b-off > 24b → pruning은 여전히 소폭 손해(단 run 간 클러스터링 이동으로 정밀 귀속은 제한).
2 · 새 병목: hard-brute regime이 D_tune에 존재하지 않는다. 세 run 모두, 잔차 질량이 가장 큰 hard-brute regime(D_expert에서 채굴)에 hard-배정되는 masked tune 행이 0개 — marginal을 잴 표본 자체가 없어 min-support에서 탈락한다. D_expert(시간상 앞)와 D_tune(val 앞 40%, 시간상 뒤) 사이에 brute 실패의 성격이 변했다는 temporal drift의 직접 증거이며, 전 계열에서 brute F1이 0.725에 동결된 원인이다. 후속 knob: tune-부재 regime의 marginal을 D_route에서 측정(fallback) 또는 검증 표본을 D_expert 후반부에서 분할.
3 · 위치. 회수층 복구는 진행 중이다 — 관문은 3배 열렸고 안전은 사상 최고(harmful 4)지만 utility 실현은 ~0.20에 머물며, 그 잔여분의 최대 항목이 바로 2의 hard-brute다. XGB(0.7548)와의 격차 −0.057의 절반 이상이 brute 한 클래스에 있다.
