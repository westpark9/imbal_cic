# EXP76 · 소규모 context의 누적·교체·고정 비교

사용자의 2026-10-15 요청과 후속 정정을 반영한다. 1,000개·20개는 설명용 예시이며 지정된 실험 수치가 아니다. 1014의 EXP72/73을 참고하되, 동일한 공격 도입 순서와 고정 test 전체를 유지하면서 적은 라벨로 context 정책을 비교한다. 승인된 v7 안의 새 실험이며 연구 버전 전환은 없다. 원고는 반영안만 작성하고 HTML을 수정하지 않는다.

## 비교 조건

주 실행은 초기 context 1,000개(Benign 750, 최초 두 공격 각 125), 이후 **신규 공격 클래스당 100개**를 공급한다. 초기 공격은 CIC2018 brute_force/dos, ToN scanning/dos이며 도입 순서는 기존 STAGES 그대로다. 두 클래스가 함께 도입되는 ToN 구간에는 200개가 공급된다. 100은 이번 비교의 명시적 실험 설정이다. 추가 규모 비교는 초기 250개·신규 클래스당 20개로 수행할 수 있으며 두 요인이 함께 바뀌므로 context 크기의 단독 효과로 해석하지 않는다.

초기·신규 사례는 기존 정제 train bank에서 seed 43으로 선택하고 모든 방법에 동일한 순서로 공개한다. 최종 공급량은 CIC2018 1,400개, ToN 1,700개다. Test는 기존 3,042,473개와 2,271,723개 전체를 재사용하며 각 행은 방법별 주 평가에서 한 번만 등장한다. 미래 공격의 라벨과 test 특징은 context 선택에 사용하지 않는다. 초기 공격 배분과 전체 라벨 예산이 1014의 10만 사례 조건과 다르므로 수치를 직접적인 개선량으로 비교하지 않는다.

## 정책

1. `pfn_accumulate`: 현재까지 공급된 모든 사례로 context 재구성
2. `pfn_fifo`: 신규 공급량만큼 가장 먼저 확보한 기존 사례 제거 후 교체
3. `pfn_similar`: 기존 context로만 표준화한 특징 공간에서 신규 학습 사례와의 최소 유클리드 거리가 작은 기존 사례 제거
4. `pfn_random`: seed로 고정한 무작위 제거
5. `pfn_fixed`: 초기 context 고정, 이후 갱신 비용 0
6. `xgb`: 동일 누적 공개 사례 전체로 CUDA hist 300 trees 재학습
7. `boostpfn`: 동일 누적 공개 사례 전체로 기존 50 learners 재구성
8. `distpfn`: 누적 TabPFN의 비용·확률을 공유하고 현재 도착 배치의 posterior만으로 보정

교체 정책은 기존 클래스마다 최소 1개를 남기는 동일 보호 규칙을 사용한다. FIFO는 확보 순서의 대리 기준이며 실제 노후화 판정이 아니다. 같은 구간의 도착 순서는 고정 seed로 결정한다. 유사도 정책도 정상·기존 공격의 구분 경계를 해칠 수 있으므로 효과는 측정 결과로 판단한다. 버린 사례는 버퍼로 다시 가져오지 않는다. 비교의 중심은 단일 TabPFN의 context 정책이며 기존 expert/S/V를 갱신하는 새 방법을 이 실험으로 주장하지 않는다. LoCalPFN은 요청에 따라 제외한다.

## 모델·평가·비용

TabPFN 8.2.0과 기존 `tabpfn-v3-classifier-v3_20260417_multiclass.ckpt`, 4 estimators, `fit_with_cache`, CPU cache를 유지한다. 가중치 fine-tuning은 이번 context 정책 비교에 포함하지 않는다. `TabPFNClassifier.fit` 전후 파라미터 동일성은 [별도 확인 기록](tabpfn_fit_mechanism_check.json)에 있다. Fine-tuning 설명은 v3 원문과 설치된 공식 `FinetunedTabPFNClassifier` 구현에 근거한다.

평가 배치는 8,192개로 지정한다. 기존 1014의 1,024개와 다르므로 latency를 직접 비교하지 않는다. DistPFN도 이 현재 배치만 사용한다. 각 정책은 초기 구축, 후속 선택/전처리·캐시/학습 시간, 첫 배치 추론, 전체 serving, GPU/RAM peak를 기록한다. GPU는 단일 worker로 실행하고 시간 측정 전후 동기화한다. 체크포인트 저장 및 결과 집계는 준비 비용에 포함하지 않는다.

이번 주 비교는 **갱신이 완료된 상태의 순차 도입 평가**이며 갱신시간은 별도 실측한다. 1014의 100/1,000행·초 지연 재생 결과를 이 실험이 재현했다고 주장하지 않는다. 신규 클래스 precision/recall/F1, 정상 오탐, 전체 Macro-F1 및 동일 구간의 기존 클래스 결과를 보고한다. 고정 context는 미등록 신규 공격의 유형을 출력할 수 없으므로 공격 여부 recall과 공격 유형 식별을 구분한다. 표본 구성이 변하는 단계 간 평균을 그대로 유지 성능의 증감으로 해석하지 않는다.

전체 공개 train과 동일 특징인 test를 제외한 공통 집합의 보조 결과도 계산한다. 이는 평가 집합 재분할이나 완전한 독립 환경 검증을 대신하지 않는다. 저장한 예측과 test ID로 혼동행렬·평가지표를 독립 검산한다. 실행 완료와 논문 근거 채택은 구분한다.
